## Status Definition

NOT RUN

Test has not been executed.

PASS

Expected behavior observed.

FAIL

Expected behavior not observed.

BLOCKED

Test cannot currently be executed.

PARTIAL

Only part of the test has been verified.

---

## Rule

Never change NOT RUN to PASS based only on code inspection.

Hardware-dependent tests require actual board evidence.
